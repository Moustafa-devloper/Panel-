# Contributing

Contributions are welcome. Please keep changes focused, Java-only, and compatible with the existing Android project structure.

## Development notes
- Keep all code and XML in Java/XML format.
- Do not add Kotlin or Compose dependencies.
- Prefer Android SDK APIs over non-standard shell commands.
- Document any privileged or device-specific behavior in code comments.

## Pull requests
- Open a pull request with a clear summary of the change.
- Include any relevant notes about testing, permissions, or unsupported device features.
